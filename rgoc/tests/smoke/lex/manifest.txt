# 腿乙 golden 清单 —— SM-M1-LEX-GOLDEN（M1-tests.md §7.2/§8；M1-design.md §8.2）
#
# 格式：<kind> <输入路径> <mode>      （三列；'#' 开头与空行跳过）
#   kind:
#     corpus      go_source_code/test/syntax/ 下的真实 Go 语料 —— U12「解除真实 Go 源码 lex」的证据
#     fixture     tools/token-oracle/fixtures/ 下的自有探针
#     hand-sparse 超限用例：检查时现场造 >64 MiB 稀疏文件（唯一手写期望；官方无此行为，T-L17）
#   mode: none | comments | directives
#
# golden 落点（由脚本派生，勿手改）：
#     corpus      -> corpus/<输入路径去掉 go_source_code/ 前缀>[.<mode>].golden
#                    （必须去前缀：.gitignore 的 go_source_code/ 规则无前导斜杠，
#                     会匹配任意层级同名目录，原样镜像会被静默排除出 git）
#     fixture     -> fixtures/<fixtures/ 之后的路径>[.<mode>].golden
#     hand-sparse -> hand/overlimit.golden
#   （mode 为 none 时不加后缀）
#
# 文件头两行（§5.2 冻结格式）：
#     # golden: <上表的输入路径>
#     # source: oracle（corpus/fixture，adapter 录制）| hand-written（仅超限用例）
#
# 脚本内置守卫（漏登记/孤儿文件/被忽略都会让门禁变红，不许静默缩水）：
#   A. 每个 golden 第 2 行必须是本 kind 登记的来源标记
#   B. test/syntax/ 的每个 .go 都必须以 mode none 登记
#   C. fixtures/ 的每个 .txt（除 char_corpus/char_golden 两个字符级数据文件）都必须以 mode none 登记
#   D. 不许有孤儿 golden（清单里没有、目录里却存在）
#   E. golden/清单路径不许被 .gitignore 静默排除（git check-ignore）
