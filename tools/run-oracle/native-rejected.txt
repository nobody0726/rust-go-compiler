# tools/run-oracle/native-rejected.txt —— native 的**冻结**拒绝面（`M'`）
#
# 判据来源：**实测**，不是从设计稿推的（`R-6-1` 同款）。
# 与 `ssa-rejected.txt` 的关系：那张是 M6 拒的（连 SSA 都没有），这张是
# **SSA 有了、但 arm64 后端拒**的。两者**不相交**。
#
# 格式：三栏，`\t` 分隔 —— `<路径>` `<码>` `<原因/证据>`。
#
# 冻结值（M9/Phase 1，2026-10-25）：`|N'| = 46`，`|M'| = 0`，合计 46（= `N` 侧全集）。
#
# 复现：
#   bash tools/run-oracle/run-native.sh tools/run-oracle/native-input.txt
#
# 两向断言在 `rgoc/crates/rgoc-driver/tests/native_slice.rs`：
#   ① `N'` + `M'` == 46（分母）；
#   ② 拒绝集合 == 本文件的路径集合（冻结后新增/消失都必须红）；
#   ③ 每条的码 ∈ `CgCode::ALL`（不许有码表外的字符串）。
#
# # 为什么从 7 行变成 0 行
#
# M7 的 7 行全部落在 `CG-UNSUPPORTED-SLICE`（`[]T` 全集）。M9/Phase 1 把切片
# 真的实现了（`make` / `Index` / `Slice` / `append` / 切片字面量 / 越界检查），
# 那 7 个文件现在都在 `N'` 里。**码本身也下线了**（`CgCode::ALL` 3 → 2）——
# 留一条永远不产出的码，会让「哪个面还不支持」有一个错误答案。
#
# 那 7 个是：`escape3` / `initcomma` / `ken/array` / `ken/convert` /
# `ken/slicearray` / `ken/sliceslice` / `ken/string`。
