## Task 9（类型参数上的内建）—— 最大产出是「类型参数进作用域」

## M12/Task 10（两个边角：`_` 与 `range`）—— 一句话：「声明位置」不是「引用位置」

* **① 接收者的形参表不解析**。官方 `collectRecv`（`signature.go:216`）= `unpackRecv`
  拆出「指针 + 基 + 形参表」→ 形参逐个 `declareTypeParam`（`decl.go:662`）→
  `instance(baseType, recvTParams)`。**实参是刚声明的类型参数自己**，形参那棵表达式
  从不过 `typ()`。所以 `func (b Box[_]) M()` 的 `_` 是**声明**。
  本仓原来两半都做了却没接上：`recv_tparam_fields` 已按官方收了声明，
  但 `resolve_func_sig` 又把整棵 `Box[_]` 交给 `resolve_type` ⇒ `Expr::Index`
  分支把 `[_]` 当类型实参解析 ⇒ `TYP-INVALID-BLANK`（4 个文件）。
  修法：`resolve_recv_generic` —— 剥 `Paren`/`*` 记层数、只解析基名、按层数
  `add_pointer` 包回。**不做 `_` 特判**：`Box[Undef]` 同一个洞。
* ⚠️ **接收者改法必须用 dump 验，不能只看测试绿**：`recv_named` 只剥一层指针再看基底
  ⇒ **指针丢了它也返回 `Some`** ⇒ 挂方法对指针丢失免疫，测试不会红。
  实测三个方法 recv = `pointer #0` / `#0` / `pointer #0`，一个没丢。
* **② `range` 第一句是 `commonUnder`**（`range.go:212`）不是 `under`。
  `under(TypeParam)` 官方返回**它自己** ⇒ `switch` 落 default ⇒
  `~map[K]V` 上的 `range` 被误报。改用 `common_under`（Task 9 的）：
  「无共同底层 ⇒ None」正好是官方那条；非类型参数仍走 `underlying`（逐字等价，
  `for i := range MyInt(10)` 的 key 仍是 `MyInt`）。
* 三个变异全红：①换回全量解析 ⇒ `gen10a` 红；②换回 `underlying` ⇒ `gen10c`

### 硬知识（M12 后续 Task 会反复用）

- **命名要两种分隔符**：`·`(U+00B7) 分隔实参、`.` 分隔复合内部。只用 `·`
  会撞名（`F[[]int]` vs `F[slice, int]` 都是 `F·slice·int`）
- **结构体段必须结构性命名**（按字段），不能按 `StructId`：`add_struct`
  不去重，每个调用点造新 id；名字跟着 id 走 ⇒ memo 命中但名字不同 ⇒
  **不动点不收敛**。`t_gen_13b` 钉的就是这条
- `BasicId::as_str()` 里 `unsafe_pointer` / `untyped_int` 带下划线 ⇒
  实例名必须过一遍消 `_`（`push_ident`）；这是「无 `_`/`$`」判据的唯一强制点
- 匿名 `interface` / `signature` / `tuple` / `union` / `typeparam` 五档
  **不结构性**（按下标）—— 代价是「多造实例」，不是「错误合并」
- **`Mono::request` 的 memo 键必须含 origin**，值比较用 `identical`
  （判失败当「不同」：宁多造不合错）；参数先 `unalias` 规范化

### 变异与陷阱

- 5 个变异全红：`mangled` 只拼名 / 不消 `_` / struct 按下标 /
  memo 丢 origin / `request` 不 `unalias`
- ⚠️ **变异「假绿」实录**：绑定挂载 mtime 整秒 + 容器缓存 ⇒ cargo **没重编**，
  跑的是上一发变异的二进制（"Finished in 0.03s" 是信号）。解法：写盘后把
  mtime 设到**未来两分钟**（`os.utime(p, (t+120, t+120))`），比 `touch` 可靠
- ⚠️ **判据无牙实录**：`request` 不 `unalias` 时全绿 —— memo 走 `identical`、
  名字走 `label_into` 的 `Alias` 臂，两条都兜住了。补
  `assert_eq!(r.args, vec![int])` 才有牙
- ⚠️ 语料脚本的 cwd 是 **`/work`** 不是 `/work/rgoc`：
  `bash tools/run-oracle/run-native.sh`（`/work/rgoc` 下没有 `tools/`）
