## 四个「数错」的教训（都是同一类：谓词打错靶）
1. `^// run$` 精确匹配漏掉 6 个带尾随参数的文件（`// run -gcflags="-l"` 等）。
2. `grep -lE '^import|"'` 把带字符串字面量的文件全误排除（69 数成 37）。
3. `grep '^import'` 被**块注释**骗：`issue50417/50417b` 的 `import "fmt"` 在 `/* */` 里，
   而这两个今天就能跑通。
4. 「带 import」≠「需要 stdlib」：`unsafe` 是 M4 支持的伪 import（5 个文件）。

⇒ 分类器改成**注释感知的 import 提取 + import 集合 ⊆ {unsafe}**，七份清单和为 266。
