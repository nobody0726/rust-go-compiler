- **本轮最有价值的实测（都进了 C7 / 代码注释 / 测试）**：
  1. **空元组是单例**：`var x func(); var y func(); var z func() ()` 只产出**一条**
     `0 tuple 0`（三个签名全引用它），而 `struct{}`/`interface{}` 两次就是**两个**号。
     这条直接决定编号，`dump` 的去重键里单列一类。
  2. **`named`/`alias` 行引用的是本体**（`named <ref(underlying)>`），不是自己 ——
     「引用定义时写 `#序号`」是**被引用方**的标签决定的。最初写错，被手算期望抓出来。
  3. `interface <m> <t>` 的 `t` = **有无项集**（`unionOf(x) != nil`），**不是** `IsMethodSet()`。
  4. **oracle 的环**：`var h interface{ comparable; M() }`（非法用法）让 `go/types` 造出
     指回自身**类型集**的 term ⇒ 后序走访无限下钻 ⇒ `fatal error: stack overflow`（吃光 1 GB 栈）。
     修法：`number()` 加 `descending` 环守卫，重入即**响亮 panic**（不改编号：合法程序里
     匿名类型不可能自引用）。结论同时是一条**对撞样本约束**：样本必须合法（C7 §5.1）。
  5. `error` 是 `named` + `interface{ Error() string }`（recv 是自己）；`any` 是 `alias` +
     空接口；`byte`⇒`basic uint8`、`rune`⇒`basic int32`（**不是**独立 basic token）。
  6. `go/types` 的 `Identical` **不比接收者**（`grep -n recv predicates.go` 无命中）；
     签名/元组的**名字不参与**；结构体的**嵌入标记 / Tag / 名字**都参与；数组长度
     `len < 0` 时**宽容**（`[...]T` 与 `[3]T` 判等）。
- **接口形态刻意偏离计划**：`identical` 返回 `Result<bool, DiagCode>` 而非 `bool`
  —— `T-TY-81` 要「稳定拒绝码」，`bool` 表达不了「不判」。`D-M3-13` 的边界
  （约束接口 / typeparam / union）走 `Err(TypUnsupportedConstraintIdentity)`；
  `x == y` 的短路**在**拒绝之前（定义对自己恒等，无需类型集推理）。
- **反向验证（人工变异，全部被抓）**：dump 一次（删 `Type::Union` 分支 ⇒ 穷尽性报错）、
  identical 四次（struct `embedded` 检查 / 接口拒绝改 `Ok(false)` / 签名加接收者比较 /
  数组长度未定改不宽容）。→ 期望值不是恒真断言。
