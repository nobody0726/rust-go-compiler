## 生成测试用例清单

- 交付物：`TEST_CASE_INVENTORY.md`（246 个功能点 → 测试用例映射）
- 方法：4 个 Explore 子代理并行分维度检索（LEX/CON/TYP/SCP/SYS、EXP/STM/BIF/PKG、AST/PIPE、Runtime），实名核对测试函数
- **关键发现（测试资源分布）**：
  - `test/` 是 Go 官方语言测试套件，**不是** `_test.go`，而是由 `test/run.go` 按首行指令（`// run`/`// errorcheck`/`// compile`/`// runoutput`/`// rundir`/`// errorcheckdir`/`// asmcheck`）驱动的独立程序。规模：顶层 ~600 + fixedbugs 2096 + typeparam 363 + abi 56
  - `src/internal/types/testdata/{check,spec,examples,fixedbugs}` 是 go/types 与 types2 **共享**的黄金语料（check 74 + fixedbugs 274），由 `TestCheck/TestSpec/TestExamples/TestFixedbugs/TestLocal` 加载
  - `src/runtime/*_test.go` 135 个；`export_test.go` 暴露内部符号（`Goid()`、`MallocGC`、`GCTestPointerClass()` 等）
  - syntax 包测试：`TestSyntaxErrors`（error_test.go）才是遍历 testdata 的函数；`parser_test.go` 不引用 testdata；`nodes_test.go:TestPos` 用位置子用例覆盖全部节点
- **事实修正（应同步到 COMPILER_FEATURE_SET.md）**：
  - `syntax/testdata` 实为 31 个文件（非 29）
  - `test/escape*.go` 实为 33 个（非 ~40）
  - `ssa/check_test.go`、`ssa/opt_test.go`、`ssa/html_test.go` 不存在
  - `gc/escape/`、`gc/walk/`、`gc/coverage/`、`gc/pkginit/`、`gc/objw/`、`gc/staticdata/`、`gc/arm64/` 无任何 `*_test.go`
  - `src/runtime/internal/` 不存在；SwissTable 测试在 `src/internal/runtime/maps/`
  - `mheap_test.go`/`mcache_test.go`/`mcentral_test.go`/`sizeclasses_test.go` 不存在
- **覆盖率**：246 个功能点中 ~236 有专项测试；9 个无专用测试（TYP-26 类型统一、SCP-06 导出标识符、EXP-16 运算符优先级、EXP-22 逻辑短路、PKG-04 零值、PKG-06 init 循环、RT-SCH-02 汇编上下文切换、RT-POLY-03 itab、RT-POLY-05 泛型字典）
- **重要结论**：`test/` 与 `src/internal/types/testdata/` 是语言级黑盒测试，只依赖编译器对外行为，可直接作为 Rust 重写实现的验收测试集
