### 五个真病因（都不是「设计没做」，是「假设是错的」）

1. **DCE 假设「读没有副作用」** —— 只在地址非空时成立。`a.h()` 的方法体是空的
   ⇒ `Call` 的 effect 全空 ⇒ 调用被删 ⇒ 接收者的 `load` 变死 ⇒ **panic 消失**。
   修法：`Load` 只在地址**可证非空**时才算纯（`AddrOf`/`Make`/`FuncAddr`/
   `MakeClosure` 及其 `Field`/`Index`/`Copy`/`Convert` 派生）。
2. **HIR 的 `x.f()` 分支给每个 `Field` 节点都标了底座类型**
   （`let typ = self.type_of(&se.x)`）⇒ `tt.fn` 的类型成了 `tt` 的类型。
   `func_sig_of_ty` 落空后退回「一个结果、类型 = 调用表达式类型」，
   而 0 结果调用的表达式类型是 `invalid` ⇒ 帧布局报「没有运行期布局」。
3. **只有 `Load`/`Store` 有 nil 检查，地址计算没有**：`&*p` 在 IR 里连指令都
   没有（就是 `p`）。新增 `Instr::NilCheck { addr }`（无 dst、DCE 永不删、
   `typing` 要求指针操作数）；`Field`/`Index` 的底座检查放后端（isel + ssa_exec）。
4. **帧是定长的，栈不是**：`ulimit -s` 8 MiB，`BigStruct` 的帧 128 MiB ⇒
   第一条访存 SEGV。超 1 MiB 的帧把**帧底**换成 mmap 零页（`fp = block + bytes`），
   槽偏移一字不改；`rt_stack_frame_alloc/_free` 成对。
5. **`print_value` 只按 `SlotClass` 分派**：接口/切片是多字聚合 ⇒ 什么都不打；
   nil map 落 `Int` ⇒ 打 `0`。改成先按类型分派（iface/slice/map/ptr），
   格式表抄 `C9` §5。

### 两条与 native 对齐的修订

## M9 / Phase 4c 收口：方法值，语料 **69/0**

`f := x.M` = 绑定点求值 + 拷贝接收者 + nil 检查 + 一个 `func(剩余形参)`。
实现：`synth_method_value_wrapper`（捕获 0 = 接收者盒子的地址）+ `box_new`
（`new(T)` + `Store`，**不是** 1 元素 slice —— 后者对接口元素只落半个值）。

### 顺带挖出六个既有 bug（都被方法值「照出来」）

1. `__imeth_` 桩**不按宽度读**接收者：`func (v byte) M()` 从 1 字节盒子里读 8 字节
   → 接口派发打出 15 位垃圾。改 `Step::LoadScalar { width, signed }`，宽度从布局取。
2. `bind_params` **单趟**：聚合形参当场 `memcpy`，冲掉后面还在寄存器里的形参
   （`rt_memcpy` 可改写 x0-x18/v0-v7）。改**两趟**。
3. **大聚合返回值只搬 16 字节**（`return_values` 把 `size>8` 当两个字）。
   `bigmap.go` 一直绿是因为**两边同时被截断** ⇒ 比较仍相等 —— 这是最阴的一条。
   改：`size>16` 在堆上拷一份、返回地址（`ret` 之后本帧就死了）。
4. `load`/`store` 对**零大小**类型仍读写 8 字节 → 踩邻居槽 / `rt_zerobase`。
   判据用「类型布局为 0」，**不是**槽宽为 0（`Invalid` 也是 0 宽）。
5. `type_assert` 对 nil 接口无脑 `ldr [x9+8]`（x9=0）→ 段错误；`rt_itab(desc,0)`
   返回非 0 → 「nil 接口断言到接口」静默成功。
6. DCE 把「没人用的**单值**类型断言」删了 —— 它失败即 panic，是可观察的。
